# Tabbit Inspired Design System

[DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/tabbit/DESIGN.md) extracted from the public [Tabbit](https://tabbit.ai/) website. This is not the official design system. Colors, fonts, and spacing may not be 100% accurate. But it's a good starting point for building something similar.

## About Tabbit

Tabbit is an AI-native desktop browser built by Lumina Lab (Meituan's GN06 team). It turns tabs into teammates -- reading pages, running tasks across websites, and keeping your context. The browser integrates web browsing, internet-wide search, AI chat, and agent-driven task automation in one native app for macOS and Windows.

The design language reflects the product: a warm, friendly, consumer-grade canvas (white warming into cream) with a single confident accent (Tabbit Orange `#F3A04C`), Montserrat typography across a wide weight range, and a dense card-driven layout built to showcase 2000+ agentic Skills. Every skill is tagged `utility` (emerald) or `taste` (violet), giving the skills grid its readable rhythm.
